Roper Technologies is a diversified technology holding company (NASDAQ: ROP) that acquires, manages, and develops niche market-leading software and technology-enabled businesses. Over three-quarters of revenue comes from software products across Application Software, Network Software, and Technology Enabled Products segments. Key subsidiaries include Aderant (legal software), Clinisys (laboratory informatics), Deltek (project ERP), Frontline Education (K-12 HR), Vertafore (insurance technology), DAT Solutions (freight analytics), ConstructConnect (construction data), and iPipeline (life insurance SaaS).
